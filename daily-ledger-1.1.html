Google Sheets Sync & Drive Backup

Connect your Google Apps Script Web App URL to synchronize all entries to a Google Sheet and store automatic backups to Google Drive. Changes are pushed automatically after each save.

A single script handles sync, pull, and Drive backup. No second URL needed.

Daily is efficient: the sheet is always live; Drive keeps rolling snapshots.

Google Drive Backups
Click "Refresh List" to see backups stored in your Google Drive folder.
Setup instructions (one time)
  1. Create a Google Sheet and open Extensions → Apps Script.
  2. Paste the Google Apps Script code (see file google-sync.gs in this folder) that handles save, get, and backup actions.
  3. Click Deploy → New deployment → Web app.
  4. Set Execute as: Me and Who has access: Anyone with a Google account (or Anyone).
  5. Copy the Web App URL and paste it above into the Google Apps Script URL field.
  6. Set DRIVE_FOLDER_ID in google-sync.gs to enable automatic Drive backups from the same deployment.
  7. Click Save Config, then Sync Now. Your ledger will auto-sync after every save and auto-backup per your frequency setting.
